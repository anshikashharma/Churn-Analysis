# Telecom Churn Analysis & Prediction
## Project Overview  
End-to-end analytics project to analyze and predict customer churn in a telecom dataset using SQL, Python, and Power BI. The goal is to identify at-risk customers and key factors driving churn.

---

## Objective  
To detect high-risk customers and understand churn patterns for better retention strategies.

---

## 🛠️Tech Stack  
- *SQL* – Data cleaning, transformation, and KPI creation  
- *Python* – Machine learning model development (Random Forest Classifier)  
- *Power BI* – Interactive dashboards for churn insights and prediction  

---

## 📊Key Insights  
- Model Accuracy: *84% (Random Forest)*  
- Retention Recall: *92% for loyal customers*  
- Churn Recall: *65% for at-risk customers*   

---

## 📊 Dashboard Preview  
Interactive dashboards were built to visualize churn trends and identify high-risk customers using both historical and predictive analysis views.
